## 2026-11-15 · 接入现货补货规则

### 用户确认

- 现货不使用 benchmark，DM 保留但禁用且不调用。
- 需求=max(0, Mini+Sales qty−Total Stock−Order Quantity)。
- 每个 item 自动比例=min(100%, 所有 CDC 库存÷完整门店需求总量)；同一 item 全部门店统一打折。
- item 可折叠查看名称、库存、需求和明细。滑块显示 0–100%，有效值为 0–自动比例上限，可手动降低。
- 先向下取整，再按原理论量小数余数补齐；缺失记录标记缺失并跳过；CDC 继续每店最多一个其他仓。
- 重复店/item、空白或非整数数量阻止计算；负销量参与公式，Mini/库存/订单不能为负。

### 本轮改动

- 新增独立现货业务模块 `existing_stock.py`，新货 `allocation.py` 与 DM 模块保持不变。
- 现货校验读取四个需求字段和可选名称，禁止重复组合，兼容 `Total Stcok`。
- 现货移除 benchmark 和未启用的仓库限制控件，DM 显示为禁用；不要求输入文件提供 benchmark/DM。
- 新增可折叠 item 详情和比例控件，超上限回退；后端独立验证比例，自动模式保持精确分数。
- 新增比例缩减、CDC 缺货及未满足需求指标，开放现货 Excel 导出。
- 输入文件变更清理本页需求及比例；比例变更清理本页旧结果，切换页面保留。
- 更新打包模块清单、界面验收脚本、测试、规则、结构和使用说明。
- 本轮仍为源码更新，没有重建 Windows exe。
