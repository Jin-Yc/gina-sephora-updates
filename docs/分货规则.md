# 新货与现货分货规则

更新日期：2026-11-27。版本：v2.0，已接入现货分货。

本文件集中记录业务规则。后续修改规则时，同步修改页面说明、对应计算逻辑和本文件，避免三个位置口径不同。

## 本轮已确认

| 项目 | 已确认约定 |
| --- | --- |
| 页面 | 左侧导航包括“新货分货”和“现货分货”，默认进入新货页 |
| 界面 | 两页共用 UI，保留旧页控件、双文件上传、检查和预览布局 |
| 数据源 | 两页沿用同样的两份文件及基础校验 |
| 状态 | 文件、检查和结果按页隔离；新货 benchmark/DM、现货各 item 比例在同一会话中保留 |
| 新货 | 常规分货保留 SOB 规则；DM 优先从库存分配，剩余库存用于常规分货 |
| 现货 | 按店铺和 item 的实际需求计算，支持自动/手动比例、CDC 出库和 Excel 导出 |
| 现货模式 | 移除 benchmark；DM 保留但禁用，现货计算不调用 DM |

## 两页共用的数据要求

1. 库存与门店清单文件包含 `SKU` 和 `Store list` 工作表，文件名不限。
2. SKU 必需列：`Material`、`Total QTY`、至少一个 `CDC数字` 库存列；库存是非负整数，`Total QTY` 等于各 CDC 库存合计。
3. 门店必需列：`store`、`curstatus`、`storename`、`cdc`；门店优先 CDC 必须有对应库存列。
4. 销售文件包含 `Material`、`Store`、`Sales qty`，支持真实 Excel 和使用 `.xls` 后缀的系统导出制表符文本。
5. 开启 benchmark 时，SKU 需要 `benchmark`（兼容 `SOB benchmark`），每行必须填写。关闭时可没有此列。
6. 开启 DM 时，SKU 和门店表需要 `DM` 列。SKU 允许 315、251、0；门店允许 1、0；空白视为 0。关闭时不检查 DM 规则。
7. 工作表名和列名忽略大小写及首尾空白；整行空白忽略；库存空白不自动补零。
8. 重复 SKU/门店、必需字段缺失、无效数字等阻止计算；重复销售组合、负销量、非整数销量和范围外销售记录给出提示。
9. 货号、店号按文本处理，保留文本前导零；数字形式的 Excel `.0` 尾缀被去除。

## 新货分货：SOB 常规分货与库存内 DM

### 销量来源与 SOB

- 未勾选 benchmark：使用 Material 自身历史销量；勾选后使用 benchmark 历史销量。缺少 benchmark 时不自动回退。
- 同一货号、同一门店的多条销售记录相加，只使用当前 Store list 中门店的销量作为分母。
- SOB = 当前店销量 ÷ 当前有效门店销量合计，有效门店范围内重新归一化。
- benchmark 仅决定占比；每个 Material 独立使用自己的库存，不与其他 Material 共用库存。

### 可分配库存与目标量

- 当前使用该 Material 各 CDC 库存合计；页面上的仓库限制控件继续禁用。
- 常规可分配库存 = 可分配库存 − DM 需求合计。DM 关闭或无适用 DM 时，常规使用全部可分配库存。
- 常规理论目标量 = SOB × 常规可分配库存。先向下取整，再按小数余数从大到小补齐；并列时按店号文本升序。
- 有有效销量且未暂停时，基础目标量合计等于常规可分配库存；新店 `-10` 不计入常规目标合计，含 DM 目标合计仍包含新店 DM 需求。

### 新店、零销量与异常

- 当前店在整个销售文件中没有记录：SOB=0、基础 allocation 和 allocation 保留 -10，不参与常规分货；如适用 DM，仍可实际出库 1 件并扣库存。
- 旧店存在历史记录，但当前销量来源在该店无销量或销量为 0：该店 SOB 和基础目标量为 0。
- 当前销量来源的有效销量总和为 0：常规库存暂不分配，但仍可从库存优先分配 DM；其余库存保留。
- 同 SKU 同店汇总后存在负销量：暂停整个 SKU（包括 DM），实际出库为 0、库存保留，最终分配量留空并提示确认。

### CDC 出库

- 每个 SKU 先最大化目标满足量，再最大化优先 CDC 出库量，最后尽量均衡各 CDC 剩余库存。
- 每店最多使用优先 CDC 和一个其他 CDC，任何 CDC 不得超库存。
- allocation 表示目标量；实际出库和各 CDC 出库表示实际安排；差额为缺货量。
- 优化未完成最优性确认时标记“出库待确认”；不能把未确认差额当成已确定的缺货。
- 每阶段优化最长 10 秒；只有库存均衡阶段超时时，保留已确认的目标满足量和优先 CDC 方案并提示。

### DM 从库存优先分配（本轮修正）

1. DM 按 Material 自身的 SKU DM 字段执行，与 benchmark 独立。多个 Material 共用 benchmark 也各自使用自己的库存。
2. DM=315：当前全部门店每 SKU 需求 1 件；DM=251：仅门店 DM=1 的店需求 1 件；空白或 0 不产生 DM 需求。315/251 表示适用范围，不要求实际门店数等于这两个数。
3. 先预留该 SKU 全部 DM 需求，再把剩余可分配库存按 SOB 计算常规整数目标。例如库存 100、DM 需求 10，常规使用 90，合计目标不额外增加到 110。
4. DM 与常规目标合并为同一次 CDC 出库优化。每家适用门店的 DM 作为必须满足的最低出库量，再最大化常规出库、优先 CDC 出库及库存均衡。
5. 两部分合计仍只能使用优先 CDC 和一个其他 CDC，不能让 DM 与常规各自再增加一个调货来源。
6. 可分配库存不足以满足全部 DM，或已确认 CDC 约束下无法满足全部 DM：暂停整个 SKU，不分配部分 DM，也不分配常规库存；实际出库为 0、库存全部保留，目标及最终分配量保留为空以提示暂停。
7. CDC 优化未完成确认与“已确认无法满足 DM”分开处理：优化待确认时相关实际出库、缺货、最终量和剩余库存留空，不发布未经确认的部分结果。
8. 新店与零销量店同样按 DM 范围参与；新店 -10 标记保留，DM 需求和实际出库单独展示。无有效销量时允许仅分 DM；负销量待确认时不分 DM。

### 新货结果字段和库存核对

- 基础 allocation：扣除 DM 需求后按 SOB 算出的常规目标，新店保留 -10。
- allocation：常规目标＋DM 需求；新店仍保留 -10，其 DM 在单独列和“含 DM 目标量合计”中统计。
- DM 需求：按 315/251 范围计算的计划需求；暂停时仍显示，不能当作已出库。
- 常规实际出库、DM 实际出库：分别展示两部分实际安排。
- 实际出库量=常规实际出库+DM 实际出库；各 CDC 出库列包括两部分。
- 最终分配量=实际出库量，不再另加 DM。暂停或待确认时最终量为空。
- 兼容旧导出的“DM 加量/DM 加量合计”列，现表示 DM 实际出库/DM 实际出库合计，已包含在总出库中，不可重复相加。
- 总库存=常规实际出库+DM 实际出库+剩余库存；每个 CDC 剩余=原库存−该 CDC 实际出库。
- 缺货量按含 DM 的真实目标与已确认出库计算；正常完成的 SKU 已保障 DM，仍有差额时属于常规目标未满足。暂停及待确认时不发布缺货量。

### 库存限制预留与导出

- CDC2/CDC3/CDC5 阈值、比例控件仅预留，均禁用，不接入两页计算。
- 后端已有预留规则：库存严格大于阈值才按比例向下取整；等于阈值不触发。预留量仍计入剩余库存。
- Excel 导出完整门店和 CDC 明细，不额外导出 SKU 汇总工作表；Store 后依次是 curstatus、storename。
- 未确定数量保留空白；新店 -10 保留；导出不会重新计算。

## 现货分货：已确认并实现

### 数据与匹配

- 继续上传原有两份文件。SKU 提供 Material 和各 CDC 库存，Store list 提供当前门店及优先 CDC。
- 销售文件除 Material、Store、Sales qty 外，现货还必须包含 Mini、Total Stock、Order Quantity。兼容表头误拼 `Total Stcok`。
- 按 Material + Store 匹配，禁止重复组合，不对销量、门店库存或订单自动相加。
- 这四个数量字段不能为空，必须是有限整数。Sales qty、Total Stock 允许为负并直接参与公式；Mini、Order Quantity 不允许为负。Total Stock 空白、小数、非数字及无穷值仍阻止计算。
- 仅计算当前 SKU × 当前门店清单。清单外记录不计入需求或分配；仍检查上传数据中的重复组合及数量错误。
- 商品名称优先使用 SKU 的 Description（兼容 Material Description），其次使用销售文件的 Material Description；缺少名称显示“未提供名称”，不影响匹配。
- 现货完全不使用 benchmark；SKU/门店 DM 不参与现货读取和规则校验，不执行 DM 加量。新货原功能保留。

### 门店需求

`原始需求量 = Mini + Sales qty − Total Stock − Order Quantity`

`需求量 = max(0, 原始需求量)`

- Sales qty=0 时，仍可能因 Mini 等字段产生补货需求，不套用新货的零销量暂停规则。
- 负销量及负 Total Stock 直接参与上述公式，只有算出的负需求被归零。例如 Mini=5、Sales qty=3、Total Stock=-2、Order Quantity=1，需求为 9。
- 店铺/item 没有需求记录时，标记“需求数据缺失，暂不分配”；需求量、理论量、目标量和最终分配量留空，实际出库为 0。不补零，也不使用 -10。
- item 需求合计只累计记录完整门店的非负需求，缺失门店数单独显示。全缺失表示需求未知，不等于已确认没有需求。

### 自动比例与手动比例

设该 item 的各 CDC 库存合计为 I，完整记录门店的需求合计为 D。

- D>0：自动比例 R=min(1, I/D)。库存不足时全部有效门店统一按该比例打折，库存充足时默认 100%。
- D=0：不产生分货目标；界面保留 100% 自动参考值，填写手动比例时自动清空并提示。
- 默认使用自动模式，计算保留精确比例，避免 2/3 等循环小数提前截断造成库存少分。
- 每个 item 在原生表格最后一列单独填写手动比例，手动值是直接乘需求的绝对百分比。例如自动 80%、手动 70%，按需求的 70% 分配，不是 80%×70%。
- 表格仅最后一列“手动比例（%）”可编辑，数字输入范围为 0–100。留空使用自动比例，填 0 暂不分配；支持连续编辑、复制粘贴多个 item。每行有效值限制为 0–该行自动上限，编辑后超上限会回退并提示，后端也独立拒绝超上限值。
- 手动精度为 0.01 个百分点，其可选上限按该精度向下取值，保证不会超库存。自动模式仍保留精确比例；两种模式的最终整数总量可能因此不同。
- 自动 100% 时也允许手动 80% 等较低值；手动 0% 表示该 item 暂不出库。剩余库存留仓。
- 所有 item 集中在原生表格展示：每行一个 item，名称、各 CDC 库存、总库存、已知需求、门店记录（完整 / 缺失）和自动比例均只读，最后一列填写手动比例。门店公式明细移到表格下方的统一折叠区，通过选择 item 查看；展开和切换页面不改变已有比例。

### 整数分配

1. 对记录完整的每店，计算理论量=该店需求×实际比例。
2. 各店先向下取整；总目标量为 floor(D×实际比例)。
3. 总目标量减去各店已取整数的余量，按原理论量的小数余数降序逐件补齐；并列时按店号文本升序。
4. 不重新使用“取整后的总目标量÷总需求”计算各店小数余数。
5. 每店整数目标不超过该店需求，目标总和不超过库存。缺失记录不参与补齐。

例如需求分别为 6、4，库存为 8：自动 80% 得到目标 5、3；手动 70% 得到目标 4、3，合计 7。

### CDC 出库与结果核对

- 沿用原 CDC 优化：先最大化目标满足量，再优先使用对应 CDC，最后尽量均衡剩余库存。
- 每家店最多使用优先 CDC 和一个其他 CDC，任何仓库不得超出该 item 库存。
- 此限制可能使总库存足够但部分整数目标仍不能实际出库；不能仅因为总库存足够就认为所有目标都能满足。
- 比例缩减量=需求量−整数目标量，表示按比例和取整减少的数量。
- 缺货量=整数目标量−实际出库量，表示 CDC 限制下未能满足的目标。
- 未满足需求量=需求量−实际出库量=比例缩减量+缺货量。
- 现货最终分配量=实际出库量，不添加 DM。
- 总库存=实际出库合计+剩余库存；各 CDC 剩余=该仓原库存−实际出库。
- CDC 出库待确认时，相关实际出库、缺货、最终量及汇总剩余保留空白并提示，不发布未经确认的缺货量。

### 操作与导出

先点击“检查文件并计算需求”，在表格最后一列按需填写比例，最后点击“计算现货分货”。清空某行手动比例后该 item 恢复自动，不再需要逐 item 勾选手动模式。
修改比例会清除旧分货和旧导出，保留需求检查及其余 item 的比例；更换、移除或清除文件会清除本页需求计划、全部手动比例和旧结果，必须重新检查。

导出 `现货分货与CDC明细.xlsx`，包括商品名称、各店四个公式字段、原始/非负需求、自动/实际比例、整数目标、比例缩减、CDC 出库、缺货和缺失状态。比例按百分比显示，店号文本前导零保留；不输出 benchmark、SOB 或 DM 列。

## 页面表格显示格式

- 整数数量使用千分位，例如 12,345；小数数量保留两位并使用千分位，例如 12,345.68；百分比保留两位，例如 66.67%。
- 同一规则应用到原生比例编辑表、数据预览、门店需求明细、SKU 汇总及分货明细。
- 货号、店号等标识保留文本，不加千分位，不去掉前导零。
- 比例表将需求记录完整门店数与缺失门店数合并为“门店记录（完整 / 缺失）”，例如“2 / 1”；两项数值仍分别保留在需求计划中。
- 仅改变页面显示，不截断计算值，不改变自动比例、手动上限或分货数量；Excel 导出格式沿用原设置。

## 结果字段补充（2.1.2）

新货和现货的每条门店结果新增“CDC 库存合计”，取该 Material 在上传 SKU 表中所有 CDC 列的原始库存合计，位于优先 CDC 后。

该列按 SKU 重复展示，用于核对单个货号总库存，不能跨门店逐行相加当作总库存。其数值不因 DM 预留、库存比例限制、手动分配比例、实际出库或门店记录缺失而改变。Excel 使用整数千分位格式；实际剩余量继续以 SKU 汇总的“剩余库存”及各 CDC 剩余列为准。
